# TaxiGo Website

A responsive ride-booking landing page built with HTML, CSS, Bootstrap, and JavaScript.

## Repository
https://github.com/siddrr4/project-portfolio

## Live Demo
Enable GitHub Pages for the `main` branch and use:
https://siddrr4.github.io/project-portfolio/

## Features
- Responsive hero section with booking form
- Glassmorphism UI elements
- Animated counters and scroll interactions
- FAQ accordion and service cards

## Notes
- Make sure GitHub Pages is configured to use the `main` branch at the repository root.
- The site is mobile-ready and styled for desktop/tablet breakpoints.
